# 04 Superposition And Polysemantic Neurons

## Voiceover

Why not inspect neurons directly? Because the network often packs many useful
concepts into fewer clean coordinates.

One neuron might help represent object closeness in one context, language target
in another, and a shortcut from a memorized episode in a third. That is the
polysemantic-neuron problem.

Sparse autoencoders are useful because they try to rotate from messy neuron
coordinates into a larger dictionary of more separable feature directions.
